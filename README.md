# Digit - ECG

Digit-ECG converts scanned 12-lead ECG sheets into aligned digital signals and heart-rate estimates. A FastAPI backend digitizes uploads, and a React frontend (currently mocked) previews waveforms and CSV exports.

## Architecture
- **API** (`api/main.py`): FastAPI endpoint `/extract-ecg-features/` accepts `multipart/form-data` with an ECG image and returns JSON records containing `{LEAD_time, LEAD_voltage}` pairs plus `heart_rate_bpm`.
- **Pipeline** (`digit_ecg_tool/ecg_pipeline.py`): OpenCV preprocessing, hard-coded lead ROIs, contour-following trace extraction, Savitzky–Golay smoothing, and an enhanced Pan–Tompkins heart-rate detector. Optional Tesseract OCR path is hard-coded to Windows.
- **Calibration** (`digit_ecg_tool/ecg_lead_calibrator.py`): OpenCV ROI picker that rewrites `ecg_lead_coords.py` for new ECG layouts.
- **Frontend** (`frontend/`): React + TypeScript (CRA) with dropzone upload, Chart.js visualization, data table, and CSV download. `HomePage.tsx` currently calls a mock processor; swap in an API call for production.

## Repo Layout
```
api/                 FastAPI entrypoint
digit_ecg_tool/      Digitization pipeline, ROI config, CLI demo script
frontend/            React SPA
results/             Example CSV generated by the pipeline
sample_dataset/      Example ECG image(s)
```

## Backend Setup
```powershell
cd C:\path\to\digit-ecg\digit-ecg
python -m venv .venv
.venv\Scripts\activate
pip install fastapi uvicorn[standard] opencv-python-headless numpy scipy pandas matplotlib pytesseract python-multipart
uvicorn api.main:app --reload --host 0.0.0.0 --port 8000
```
Update the Tesseract path in `digit_ecg_tool/ecg_pipeline.py` or disable OCR if unavailable.

## Frontend Setup
```powershell
cd C:\path\to\digit-ecg\digit-ecg\frontend
npm install
npm start
```
Integrate the API by replacing the mock processor in `frontend/src/pages/HomePage.tsx` with a POST to `http://localhost:8000/extract-ecg-features/`.

## API Details
| Method | Path | Body | Response |
|--------|------|------|----------|
| POST | `/extract-ecg-features/` | `file` (image) | JSON array with per-lead time/voltage columns and `heart_rate_bpm` |

## Key Notes
- Lead coordinates are static; regenerate them for different ECG templates using the calibrator script.
- Debug plotting (`matplotlib`) runs by default; disable before deploying headless workers.
- Add CORS, file-size checks, and auth before exposing the API.
